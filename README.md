# Data Science Mastery Path

A free, structured, module-wise Data Science training program — entry level
to master level, with runnable Python code in every module and a hands-on
project at the end of each level. Covers the day-to-day data science
workflow: statistics, EDA, visualization, experimentation, and communicating
findings — distinct from the model-building focus of the AI/ML track.

**Live site:** https://sigilipelli.github.io/data-science-mastery-path/

## Contents

- **Level 1 · Entry** — what is data science, Python for data science, data cleaning, EDA, visualization, statistics fundamentals, correlation & regression, messy real-world data, communicating findings, capstone report
- **Level 2 · Intermediate** — advanced pandas, statistical testing, plotly, feature engineering, intro ML, time series, A/B testing, SQL, Jupyter best practices
- **Level 3 · Advanced** — advanced statistical modeling, causal inference, forecasting, big data, model interpretability, executive storytelling, Streamlit dashboards, reproducible research, data ethics
- **Level 4 · Master** — leading data science teams, advanced causal inference, DS platforms, MLOps, experimentation at scale, strategy, stakeholder management, governance, career growth, capstone
